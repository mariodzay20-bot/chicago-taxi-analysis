# Chicago Taxi Market Analysis

## 📊 Project Overview
Analysis of Chicago taxi market data to identify demand patterns and evaluate market opportunities for a new taxi company.

## 🎯 Objectives
- Analyze demand patterns by location and company
- Test hypothesis about weather impact on trip duration
- Generate actionable insights for market entry strategy

## 🛠️ Technologies Used
- Python, Pandas, NumPy
- Matplotlib, Seaborn
- Statistical hypothesis testing

## 📈 Key Findings
- Peak demand occurs in downtown areas during weekdays
- Weather conditions significantly impact trip duration (p < 0.05)
- Market opportunity identified in underserved neighborhoods

## 📁 Project Structure
- `notebooks/`: Jupyter notebook with complete analysis
- `data/`: Raw datasets used in analysis
- `images/`: Visualizations and charts

## 🚀 How to Run
1. Clone repository
2. Install requirements: `pip install -r requirements.txt`
3. Run notebook: `chicago_taxi_analysis.ipynb`
